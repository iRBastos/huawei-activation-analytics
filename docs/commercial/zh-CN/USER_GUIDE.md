# Huawei Activation Analytics V2.1 — 商业用户指南

**适用于渠道经理及商业团队。** 本指南说明如何从**按安装商记录的华为激活量**中发现值得关注的变化，并转化为有依据的沟通和市场行动。

## 1. 安全开始使用

下载或解压项目，在现代浏览器中打开根目录的 `index.html`。离线版本不需要服务器或网络连接。使用 **Explore fictional demo** 可体验虚构数据，不会覆盖真实工作区。真实数据在允许的情况下保存在当前浏览器及用户配置中；否则会显示 **Session-only workspace**。关闭页面、移动文件或更换设备前，请通过 **Data → Backup & guide → Download full backup** 下载完整备份。

## 2. 首先导入可靠的安装商数据

1. 进入 **Data → Installer imports**，选择受支持的 `.xlsx` 或 `.csv` 月度矩阵：每行一个安装商、每列一个月份；可选的末尾 Total 列会被忽略。
2. 核对工作表、表头行及公司名称列。同一文件中规范化后重复的名称按月**求和**；`Total`、`Grand Total`、`=== 总计 ===` 等汇总行不会成为安装商。
3. 将预览结果与原始总数核对。重新导入相同来源/月份的记录会**替换**而不是重复累加。
4. 默认选择更稳妥的 **Partial update**；只有确认导入月份覆盖全部相关安装商时，才选择 **Full installer population**。导入月份列中的空白单元格代表零；部分更新中缺少的月份或安装商代表**未知**。
5. 确认导入并查看历史记录。在 **Installers → Installer overview → Account management** 中，先人工核实相似名称是否属于同一公司，再合并。确认后各来源的激活量求和，并保留来源信息。

**商业影响：** 错误的零值可能制造虚假的停滞或下降信号。检查覆盖范围是商业管理的重要组成部分。

## 3. 识别可能的活动需求变化

打开 **Installers → Insights & priorities**。选择已结束的 **From / To** 时间段，与长度相同的上一时期比较，检查覆盖情况。建议先使用默认门槛：**最低 5 次激活**和**至少 20% 变化**；确有必要再调整。

检查 **High**、**Medium**、**Low** 与 **Data check** 队列。信号包括显著增长/下降、连续三个月确认零激活、恢复活动、三个零值月份后首次记录活动，以及零比较基线后的活动。这是可解释的规则，**不是客户流失预测**。可通过 **Export all insights CSV** 导出证据和建议后续行动供内部跟进。

## 4. 调查具体合作伙伴

在 **Installers → Installer profile** 中按安装商名称或历史别名搜索。查看选定期间的数据、月度/季度/年度走势、最后一次正激活、历史高点、缺失月份及来源证据。比较可比期间，形成需要向客户核实的问题。注意区分真实业务变化与导入、日历或上报问题。

## 5. 比较安装商之间的变化

**Installers → Compare 2–6** 可同时比较 **2 至 6 家**安装商的数量与趋势。只有所有选中账户在图表首个报告区间的基线**完整且大于零**时，才能显示以 100 为基准的指数图；否则使用绝对激活量。不同规模账户的增长表现不能仅凭绝对数量判断。

**Installers → Installer overview** 提供排名、样本占比、活跃账户、留存、集中度及月度活动热力图。这里的占比只代表**已跟踪的华为安装商报表样本**，不是整个爱尔兰太阳能市场份额。

## 6. 查看华为产品总体走势

使用 **Overview**、**Inverters**、**Batteries & BMS** 和 **Comparisons** 查看产品总体激活量及组合变化。**Targets** 使用人工设定的目标。安装商数据与设备数据是**相互独立**的，能够分析整体电池/逆变器趋势，但不能据此声称安装商 A 使用了型号 B。

## 7. 将洞察转化为行动

针对重点账户：**（a）** 核实数据；**（b）** 在账户档案中量化变化；**（c）** 联系安装商确认原因；**（d）** 根据需要提供库存协调、培训、调试支持、产品定位或分销商协助；**（e）** 在应用**之外**的 CRM 或行动日志中记录负责人和复访日期；**（f）** 在下一期完整数据到来后复盘。

请参考[渠道经理行动手册](CHANNEL_MANAGER_PLAYBOOK.md)中的行动矩阵、虚构案例及建议响应时间。系统**不会**自动向安装商发送邮件、更新 CRM 或连续获取实时数据。

## 8. 重要定义

| 术语 | 正确含义 |
|---|---|
| **Activation** | 已记录的华为设备激活，不等于已证实的销售、收入或家庭安装数量 |
| **Declining / Growing** | 完整、等长时间段之间达到设定门槛的显著变化 |
| **Inactive** | 连续三个**已结束且完整上报**的零激活月份，并有更早正激活记录 |
| **Data check** | 原始数据或期间不足以得出可靠商业结论 |
| **Installer share** | 已跟踪的合格样本占比，而非全国市场份额 |
| **Priority score** | 用于确定调查顺序的规则评分，不是流失概率 |
| **Product mix** | 总体产品激活数据，不能确定具体安装商选择的型号 |

## 9. 导出、隐私及常见问题

- 按需要导出 CSV 和完整备份，机密客户数据应放在获批的内部存储位置。
- **为什么没有增长百分比？** 检查数据是否完整、期间长度是否一致、分母是否为零。
- **为什么找不到安装商？** 搜索别名、检查导入覆盖范围及账户完整选择器。
- **为什么停滞提醒似乎不准确？** 核实三个已结束月份、来源证据和缺失数据。
- **为什么不能显示指数图？** 某账户的初始基线可能为零或不完整。
- **移动 HTML 后数据为何不见了？** 本地存储受浏览器、用户配置和文件来源影响；使用 JSON 备份恢复。
