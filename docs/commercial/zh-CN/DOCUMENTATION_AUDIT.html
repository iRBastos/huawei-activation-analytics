商业定位

首先将产品介绍为渠道商业智能分析工具：识别安装商激活数量的显著变化、核实数据覆盖情况、确定优先沟通对象，以及组织留存、恢复与增长行动。技术操作仍放在使用手册中，但项目介绍应优先说明商业决策价值。

已核实的功能

  • 安装商总览、排名、活跃账户、集中度、留存、动量和历史趋势。
  • 可搜索的安装商档案及 2–6 家安装商对比。
  • 可解释的 Insights & priorities：可配置阈值、连续零激活、重新活跃和数据覆盖检查。
  • 月度 XLSX/CSV 导入、经确认的名称合并、原始数据证据和 CSV 导出。
  • 独立的设备分析、浏览器本地离线存储及 JSON 备份。

交付范围和限制

文档包含项目介绍、渠道经理行动手册、使用手册、快速入门与文档审查，均提供英语、巴西葡萄牙语和简体中文版本，并包括 Markdown 和离线 HTML。

该系统依赖月度数据导入，并非实时预警系统、CRM、竞争对手追踪工具、需求预测工具或市场份额计算器。建议的联系时限属于业务流程，不属于软件自动功能。不包含 PowerPoint。

发布原则
